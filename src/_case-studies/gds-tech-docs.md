## The challenge

The existing technical documentation template needed improvements to increase adoption and ensure a consistent, high-quality standard for technical documentation across government departments, ultimately saving development time.

## My role

I was responsible for gathering input and feedback from various stakeholders who were using or considering the template. I facilitated ideation sessions and discussions to find effective solutions and managed the implementation of key improvements. These included adding features like autocomplete search and multi-level navigation.

## Impact

The improvements to the template resulted in increased engagement and wider use across government. This significantly saved development time for individual teams while raising the consistency and quality of technical documentation across the board.
